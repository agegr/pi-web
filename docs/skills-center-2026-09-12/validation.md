## 2. 自动检查

执行本目录的 python validate-deliverables.py，仅使用 Python 标准库。结果保存为 [validation-results.json](validation-results.json)。

检查内容：

- 根目录 Markdown/HTML 的本地链接与 HTML 锚点。
- F01–F22 唯一且完整，每项至少三个验收用例，验收 ID 不重复。
- 图稿 ID 为 00–12，无缺失/重复；PNG 文件存在、格式头、尺寸、桌面与手机方向。
- 每次生成引用的图片文件存在。
- 原 01–08 与历史图文件的 SHA-256 不相同，避免图稿索引已更新但图片仍为旧版。
- 五领域顺序与 ID 正确，子分类 ID 无重复，与 API 合同的名称映射一致。

这个脚本不能阅读图片中的文字，不检查图中按钮的真实点击行为，也不证明页面实际适配 390 CSS px。完整运行结果以 JSON 为准；图片内容由另外的逐图视觉审阅核对。

## 4. 文档一致性核查

分类与安装身份独立；多域归属不复制 canonicalSkillId。分类没有证据时待分类，不默认计算机；目录和外部结果统计分开；安装/更新原有的共享绑定、revision、幂等与核验合同保留。

管理页初始全部领域，不隐式继承发现页范围；用户在管理页主动选的领域才在已安装/更新之间共享。检查全部领域始终检查当前授权范围内的全部实例，结果显示可过滤并报告隐藏数量。

分类初稿 JSON 是设计定义，未接入应用配置；真实技能映射须有来源证据后另行维护。没有以图稿示例替代实际分类索引。
