## 本次调整

技能中心覆盖 **计算机领域、金融领域、哲学领域、心理学领域、玄学领域**。原先设计中的前端设计、代码审查、文档工程等下沉到计算机领域的二级方向；五个领域平级，不把其他领域塞入计算机分类。

内容层次为“领域 → 细分方向 → 技能”。发现/已安装/更新仍是操作视图。领域归属与项目/全局安装位置独立；跨领域技能可以有多个标签，但共用技能身份和已有安装实例。

## 数据与行为边界

领域配置不等于上游市场已经提供领域分类。第一期使用可版本化、可追溯真实来源的人工分类索引；已收录目录与外部搜索分开，未知归属标记待分类，空领域显示真实空态。

全部领域管理包含待分类技能；检查全部领域不会被当前显示筛选缩窄。模型展示开关、下一次资源加载、同名/共享实例、单技能更新、幂等和结果核验保持原合同。

图中的 demo-team 来源、数量、哈希和技能内容均为设计示例，不能作为生产数据。玄学暂按传统术数与象征研究组织，二级方向可继续调整。

可按领域、图号和区域提出修改，例如“09 金融增加宏观研究”“12 玄学调整细分方向”“04 跨域标签改到名称下方”。
