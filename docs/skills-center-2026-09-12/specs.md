# 技能中心：逐功能实现 Spec

实施状态与逐条验收证据：[实施与验收记录](IMPLEMENTATION.md)。设计目标与实现验证状态分别记录。

版本 1.2 · 2026-09-12 · 所有“必须/应”构成验收合同；实现与已执行证据逐条记录于 acceptance.md，不表示 71 条已全部通过。

上位文档：[PRD](PRD-skills-center.md)。数据结构、路由、状态枚举以 [API 合同](api-spec.md) 为准；版式以 [设计文档](DESIGN.md) 为准。

## 通用规则

- 所有写操作使用服务器解析的上下文和目标；前端路径展示不构成授权。项目上下文以实际 cwd 为准，不把主仓库和 worktree 默认为同一安装位置。
- 异步请求携带当前上下文键和请求序号。旧搜索、旧项目、旧详情响应不得覆盖新页面。
- null 表示未知，不等于 0、false、未安装或安全。空列表与请求失败分开。
- 成功以重新读取结果为准；状态无法确认时使用“结果待确认”。不自动重试写入。
- 远程内容只读展示，来源文本不会触发技能安装、脚本执行或权限设置。
- 关闭界面不取消服务器操作；安装和更新没有第一期取消/回滚接口。必须在运行态说明这一点。
- 例子中的 `demo-team/*`、短哈希和占位路径仅供设计/测试，禁止写入生产数据源。

## F01 入口、项目上下文与导航恢复

**目的/入口：** 从原技能设置入口进入新技能中心；工作台已有入口保持可达。首次进入默认“发现”的五领域总览；明确管理/更新入口可直接到对应操作页，其领域筛选初始为全部。已选一级页在同一浏览器标签生命周期内恢复。

**输入与输出：** 输入当前 cwd（可为空）、来源页面和已有筛选；输出完整技能中心视图。顶部展示项目短名，展开信息可查看服务端提供的完整 cwd。无项目显示“未选择项目”。

**行为：** 发现/已安装/更新切换不执行写入；详情保存进入前查询、筛选、滚动与焦点。返回恢复原状态。关闭返回原工作台，不清除会话。不把本机绝对路径写入 URL；同一页内部状态可用组件路由状态保存，不要求独立 Next 页面。

**项目变化：** 重新加载本地清单与更新结果；市场搜索关键词可保留，卡片的安装标记必须重新计算。已打开安装确认面板失效并重新预检；已提交操作继续使用提交时捕获的项目，不能被顶部选择器改变。

**异常：** cwd 被删除或不再授权时显示上下文错误并提供返回/重新选择；不得悄悄切换全局安装。

**验收：**
- F01-A：在项目 A 搜索后进入详情，返回时关键词、排序与结果位置保留。
- F01-B：A 的清单请求晚于切换 B 的响应完成，页面仍只展示 B 的本地状态。
- F01-C：A 安装已提交后切换 B，操作结果仍注明 A；B 卡片不能被标记为项目已安装。

## F02 市场搜索与快捷搜索

**入口/数据：** 进入具体领域后的外部搜索框；领域总览不直接混排市场结果。首个 provider 固定 skills.sh（来源标签，不画无用来源选择器）。提交 trim 后的 query；空字符串回到首次进入态，不请求全部市场。上限由服务端契约返回/统一校验配置，前端同源读取。

**行为：** Enter 或“搜索”提交；输入本身不发请求。清除按钮清空查询和结果。快捷词读取当前领域配置，点击后作为普通关键词提交，标签为“外部快捷搜索”，不当作源站分类；计算机词组不得成为其他领域的默认分类。领域内首次进入显示已收录目录与覆盖说明；外部结果单独分区，不伪造推荐榜。

**响应：** 每次显示“本次返回 N 项”；N 是去重后当前响应项目数，不是全市场总数。不提供没有 cursor/total 的分页按钮。服务端保留来源顺序并报告 `searchMode`；使用 CLI 后备时可显示“通过命令行搜索获得”。

**状态：** idle → loading → success / empty / error。已有结果上启动新搜索时可以保留旧结果，但标注“正在更新”，在新查询完成前禁用旧结果的安装按钮，防止错认。Abort 旧读取请求仅用于客户端节流，不当作服务器任务取消。

**异常：** API 与 CLI 都失败显示错误和重试；不能显示“没有技能”。限流给来源与可用重试时间，未知时不倒计时。登录过期按 F14 共用错误处理。

**验收：**
- F02-A：空白提交无网络搜索；快捷词与手动输入同词的请求语义相同。
- F02-B：快速提交 A、B，A 最后返回也不能覆盖 B。
- F02-C：上游失败且后备失败显示 error；正常空结果显示 empty，两个状态分别测试。

## F03 结果卡片、排序与安装标记

**数据：** canonicalSkillId、classification（含多个领域/二级类目及待分类）、名称、来源、描述（可 null）、安装量原文/可比较值（可 null）、详情可用状态及安装实例摘要。

**信息顺序：** 技能名称 → 用途最多两行 → 来源 → 安装量（有数据时）→ 已安装状态/操作。摘要仅来自已解析原始描述，不用未经标识的 AI 文本替代。缺失显示“来源未提供用途说明”。不强行把每张卡片改成自创中文品牌名。

**排序：** 外部搜索默认“源站顺序”，指本次返回顺序，非相关性承诺。可切换“安装量”，仅对本次返回集合降序；未知值置尾，同值按原顺序。只有格式化字符串、无法无歧义解析时，numeric 值为 null，不能把 1.2K 当成精确原始计数。

2026-09-12 修正：1.2K 等可识别缩写保留 numeric=null，显示“约”，并以单独推导的近似值参与排序；未知值仍置尾。整数采用千位分隔，统一单位为“次安装”，并注明 CLI 安装量不代表独立用户数。

**匹配：** 安装标记按来源技能身份 + 本地实例匹配，不按 name 单独匹配。同一技能可同时显示“项目已安装”“全局已安装”。资料不完整无法匹配时显示“安装状态未确认”。多个结果指向同一 canonicalSkillId 合并，保留第一项及较完整的可验证元数据。

**操作：** 标题/查看详情进入详情；“安装…”打开 F06，不直接写入。已安装卡片主动作“管理”，详情仍可为另一个作用域打开安装面板。

**验收：**
- F03-A：两个仓库均有 review，安装 A 不得使 B 显示已安装。
- F03-B：项目和全局都存在时两个标记均显示，管理入口能定位相应实例。
- F03-C：缺失安装量置尾并显示未提供，不渲染 0 或虚构排行。

## F04 技能概览与来源详情

**入口/输入：** 发现卡片传 canonicalSkillId；本地行传 installationId。远程与本地详情分开标记“源站内容 / 本地内容”，不得安装后继续将本地改动误标为源站原文。

**内容：** 名称、原始描述、来源链接、技能相对路径、读取到的提交/内容标识；概览使用原始描述及 SKILL.md 已有说明，不自动生成未核实的用途承诺。设计图中的“适合什么任务 / 使用方式”有对应原文时呈现；没有则展示说明正文和“未提供使用示例”。

**布局与动作：** 概览 / SKILL.md / 文件三个标签；桌面侧栏来源信息，移动端折叠在正文后。未安装主动作安装；已安装主动作定位管理。多实例情况下先选“当前项目/全局/具体路径”，禁止隐式修改第一项。

**版本：** 分别标明远程读取提交、安装锁定内容哈希及检查结果算法。缩略值可复制完整值；不同哈希算法不能用箭头表达可比较版本。无信息显示未提供，不伪造 v1.0。

**异常：** 详情元数据失败不抹除原搜索结果。提供重新读取与外部源链接；未能明确定位唯一 SKILL.md 时，不自动选择第一个文件，显示无法唯一定位。详情读取失败不等于技能不兼容；保留 F06 可用性由预检决定。

**验收：**
- F04-A：远程与本地同名详情可区分内容来源和具体实例。
- F04-B：没有描述/版本/许可证，页面分别呈现缺失状态；不编造。
- F04-C：仓库内出现多个同名 SKILL.md 且不能唯一匹配时返回 ambiguous，禁止假装已解析。

## F05 SKILL.md 与文件只读预览

**数据：** 服务端解析的 snapshotId、相对文件路径、媒体类型、大小、文本或不可预览原因。先读取文件清单，再按需读取所选文件；不一次下载整仓库到浏览器。

**行为：** SKILL.md 默认安全 Markdown 渲染，可切换原文与复制。文件标签提供按路径的目录列表和预览；大文件可提示超出配置限额并提供受校验的外部原文件链接，不将截断文本伪装完整内容。复制按钮只复制已加载文本，并反馈成功/失败。

**安全边界：** 禁止原始 HTML、脚本、iframe 和危险 URL 协议。远程图片默认不加载，显示替代文本及可主动打开的来源链接，避免页面读取触发外部追踪。文件路径必须在解析出的技能目录内；拒绝 `..`、绝对路径、编码穿越以及越界符号链接。远程重定向仍需校验目标主机；文件名不成为 shell 命令。

**一致性：** 同一详情会话的文件树和内容按 snapshotId 固定到同一读取提交；刷新详情显式获取新 snapshot。远程预览快照不代表之后安装必然固定该提交，F06 必须说明这一点。

**验收：**
- F05-A：包含 `<script>`、javascript 链接、远程图片的文档不执行/自动请求这些内容。
- F05-B：路径穿越和越界链接被拒绝；正常嵌套文本可读取。
- F05-C：切换文件时旧响应不能替换新文件，二进制/过大文件给明确原因。

## F06 安装预检与目标选择

**入口：** 卡片或详情“安装…”；输入 canonicalSkillId、当前 cwd 与明确 scope，调用服务端预检生成 planId。可用项目存在时默认“当前项目”，无项目默认“全局”；这是显示默认值，必须由用户点击“确认安装”才执行。

**预览内容：** 技能名称/来源、Pi、作用域、项目名称、服务端解析的逻辑目标路径；若为共享物理目录/符号链接，展开显示实际位置与影响范围。不写死 `~/.pi/agent/skills` 作为所有环境的事实。

**预检项目：** 来源语法与 CLI 能力、目标授权和项目信任、实例是否已存在、同名冲突、目标可写性、正在进行的写操作、来源解析能力。预检不能执行安装或隐式信任项目。

**已有安装：** 同作用域同实例已存在，显示“已安装”并去管理；不提供静默覆盖安装。不同来源占用同目标返回 conflict。另一作用域存在可继续，但说明有多个实例及加载结果依 SDK 规则判断。

**来源变化：** 面板显示“将安装执行时源站可用内容；此预览不固定版本”。若预检时已知内容较详情快照变化，提示重新查看；计划失效或项目变更必须重做预检，不能沿用旧路径。

**状态：** loading / ready / blocked / error。ready 才能提交。项目未信任时项目选项不可提交，解释原因，可主动切换全局；不自动切换。

**验收：**
- F06-A：不同 cwd、XDG/Agent 目录配置下目标从服务器返回，页面不拼接假路径。
- F06-B：已有同实例再次打开显示管理；同名异来源不被覆盖。
- F06-C：计划生成后切换 scope/cwd，确认按钮失效直到新计划返回。

## F07 安装执行、核验和结果

**提交：** 发送 planId、idempotencyKey 及所需确认字段；服务器重新校验当前授权、计划指纹和目标冲突，原子取得共享写入门闩后返回 operationId。双击或同 key 重发返回同一操作，不启动第二次 CLI。

**执行：** 复用参数数组调用 skills CLI，限定一个具体技能并指定 Pi；全局/项目参数按已验证计划构建。第一期主机同时只执行一个技能安装/更新写任务，其他写请求明确返回 busy，不暗中排队；读页面仍可用。

**展示：** 安装中 → 核验中 → 成功 / 失败 / 结果待确认。阶段来自服务端实际状态，不编造百分比。运行时可以关闭面板，顶部提示“操作继续运行”；返回可恢复查看。CLI 日志折叠呈现、限长与脱敏，不作为普通流程主内容。

**核验：** 重新读取目标 SKILL.md、实例身份、锁信息与加载诊断。找到预期实例且文件可解析才成功；若已写入但不能映射预期实例，标记 needs-review 并显示检查动作。核验记录实际版本，不能无条件沿用预检快照。

**成功：** 显示作用域/项目/真实目标与“下次资源加载时按当前配置处理”；有遮蔽、配置排除等诊断时单独显示。按钮“查看已安装”，跳转并定位实例。当前会话不自动发送提示或重新加载资源，成功写入不保证任意会话立即可用。

**失败：** 保留目标与原因；操作终止且重新预检完成后才能显式重试。超时、断线或主机重启状态未知时先恢复查询/核验，不能立即重装。

**验收：**
- F07-A：相同 key 连续提交，只出现一个 CLI 子进程和同一 operationId。
- F07-B：CLI 返回成功文字但文件不存在，不能进入 succeeded。
- F07-C：浏览器刷新后恢复原 operationId，不再次安装；成功后定位正确项目实例。

## F08 本地安装与资源清单

**范围：** 当前主机的授权全局配置根、所选且可信项目的配置根、可追踪锁记录及 SDK 已加载资源。第一期不是整机磁盘扫描器，不扫描未选项目、不遍历任意家目录。标题下说明“当前项目与全局的可访问技能”。

**聚合：** 被动枚举已配置根的 SKILL.md 和已追踪实例，复用 SDK 的目录发现规则/配置解释；禁止为取清单加载扩展脚本。随后与 SDK 的有效结果和 diagnostics 关联。真实路径相同的链接合并成一个物理实例并列出访问入口；不同物理副本保留独立实例。合并时保留每个管理入口的 lock/ref/版本信息，不能随意挑一个作用域或哈希代表所有入口。存在多个管理绑定时，第一期检查/更新为 unsupported/blocked，说明“共享目录有多个管理记录，无法唯一确定更新来源”；仍可只读和确认共享影响后修改模型展示设置。

**身份：** 来源技能 canonicalSkillId 与本地 installationId 分开。installationId 根据规范化真实路径生成稳定不透明标识，响应携带 scope 和 context；该 ID 不授予权限。未有来源可保留本地资源，`managed=false`，不得从同名远程技能借用更新元数据。

**加载结果：** effective（当前配置加载）、shadowed（有已核实同名遮蔽诊断）、excluded（配置排除）、untrusted（项目未加载）、invalid（解析失败）、unknown（无法关联）。不能仅凭 scope 猜“项目优先”。全局可见资源未必被特定活动会话加载，表头写“当前配置加载”，避免“当前会话可用”。

**缺失文件/锁：** 文件存在而锁缺失，作为本地/来源未追踪；锁存在而文件不存在，进入诊断记录，不显示健康安装行。坏锁解析错误可见，保留可读取的其他实例。返回 coverage 和 partial，部分读取失败不清空全部列表。

**验收：**
- F08-A：项目与全局有同名不同文件，保留两行，加载结果依据 SDK 诊断标注。
- F08-B：两个链接指向同一文件，合并实例且保留各管理绑定；多个锁记录时检查/更新阻断，开关变更提示影响两个访问入口。
- F08-C：未追踪本地技能仍可见，锁文件损坏不会把全部技能当作未安装。

## F09 已安装搜索与组合筛选

**输入：** 本地清单、query、scope、source、modelVisibility、updateState、loadState、domainId、categoryId、classificationState。领域筛选按 F22 默认全部，待分类不能遗漏。先获取完整覆盖范围内清单，再本地组合筛选，不依赖远程市场。

**规则：** 名称、描述、来源做大小写不敏感的子串搜索，trim 前后空白；筛选组间 AND，组内单选。默认全部作用域、全部来源、全部可见性、全部更新状态。显示“显示 M / N 项”，N 为当前读取范围内健康实例数，不含诊断记录。

**布局：** 默认紧凑列表，列为技能/来源、领域、位置、当前配置加载、向模型展示、更新状态、更多。领域支持多个标签或待分类，不挤占安装范围字段。不另造卡片/表格切换作为第一期功能。移动端每实例一个信息块。

**空态：** 总实例为零给“发现技能”；筛选后零项给“清除筛选”；清单失败给重试，三者分开。来源选项由当前数据派生，未知来源有单独选项。

**验收：**
- F09-A：离线且已有清单时本地搜索和筛选仍可使用，旧数据带读取时间。
- F09-B：查询、项目、隐藏三个条件按 AND，清空筛选恢复全部清单。
- F09-C：列表按 installationId 保持行身份，重名行的开关和菜单不串行。

## F10 向模型展示与手动调用

**控件：** 列标题“向模型展示”；checked 对应 `disableModelInvocation=false`。通用关闭说明“对模型隐藏；此设置不禁止手动调用”。只有当前配置已加载且名称能唯一定位的实例，才显示“仍可通过 /skill:<name> 手动调用”。被遮蔽、配置排除或未加载实例不得承诺可直接调用。禁止使用“关闭执行权限”“彻底禁用”或“卸载”。

**提交：** installationId、期望文件 revision、明确布尔值。服务器实时验证实例归属、授权真实路径、SKILL.md 文件名/有效 frontmatter 及文件版本；文件变更返回 conflict。仅修改对应 frontmatter 字段，保留其他键、正文、换行风格和可保留的格式。

**状态：** 单行 saving 时禁用该开关；成功后用返回值替换并提示“已保存，下次加载资源生效”；失败回到最后已确认状态，错误紧邻该行。不让全页不可用。

**共享文件：** 一个物理文件被多个入口引用时先显示影响范围；修改作用于该物理文件。并发安装/更新占用门闩时返回 busy，不能与 CLI 同时覆写。

**手动调用：** 详情提供只读 `/skill:<name>` 及“复制调用命令”。仅在名字可唯一映射到当前有效资源时提供复制；存在歧义/未加载时解释限制。复制不会自动发送到对话。

**验收：**
- F10-A：关闭开关仅写 true，开启删除该键，其他 frontmatter 与正文不变。
- F10-B：外部编辑后 stale revision 被拒绝，不覆盖新文件；非布尔输入返回 400。
- F10-C：关闭后提示此设置不禁止手动调用，仅唯一已加载实例展示调用命令；不自动打断会话，共享文件显示影响范围。

## F11 信任、冲突与诊断

**来源：** SDK ResourceDiagnostic、根目录枚举/锁解析错误、安装结果核验信息。原始诊断做结构化归类，保留可展开的原文；不能把未知诊断强行归为安全风险。

**显示：** 页头小型诊断条显示条数并展开列表；实例行有相关状态，详情可查看关联路径。同名冲突明确列出加载与未加载位置，依据 SDK 实际结果；解析失败列出文件与修复提示。

**动作：** 查看相关实例、重读清单、进入已有项目信任流程。第一期不自动删除重复技能、修复用户文件、修改加载顺序或授予信任。权限不足不展示越权文件正文。

**验收：**
- F11-A：SDK 同名冲突诊断在界面可见，不出现虚构的项目优先结论。
- F11-B：坏锁文件错误可展开，其他正常实例可继续管理。
- F11-C：点击处理信任只进入现有流程，不能因打开技能中心就写入信任状态。

## F12 检查更新与更新中心

**入口：** 更新页“检查全部”、单项“检查更新”。每次只检查当前上下文覆盖范围内的可识别实例。没有检查过的实例为 unchecked，而非 up-to-date。

**规则：** 对每个 installationId 捕获 currentRevision，首先验证唯一管理绑定，然后执行既有可比性判断：受支持 GitHub 来源、技能路径、有效当前哈希和适用 ref 条件。共享实例有多个管理绑定时返回 unsupported，不任选一个 global/project 锁记录。项目 pinned ref 当前不支持比较；保留 unsupported 原因。不将不同作用域或算法的 hash 混比。

**状态：** unchecked → checking → up-to-date / update-available / unsupported / error。记录每项 checkedAt；HTTP 200 不等于所有项成功。检查全部允许部分成功，摘要准确报告每一类数量。界面筛选默认“可更新”，没有可更新时显示其余状态入口。

**缓存：** 仅在相同实例内容 revision、算法、源 ref 下复用；本地修改、安装/更新或上下文切换失效。检查中当前文件发生变化，结果标 stale，要求重查，不展示可点击的过期更新动作。

**异常：** 网络错误显示重试；未支持显示原因及源链接；没有 hash 显示“缺少可比较版本”。手动点击检查不自动执行更新。

**验收：**
- F12-A：同批次含最新/可更新/不支持/失败，四种数量和状态正确。
- F12-B：一项限流不让其他项被标记失败或最新；重试只重试明确选择项。
- F12-C：检查期间实例被外部修改，旧检查结果不得触发更新。

## F13 单技能更新预检与执行

**入口：** update-available 行“更新…”或详情更新入口。确认面板列技能、实例、项目/作用域、当前和检查到的源版本、checkedAt、实际目标、变更影响。主按钮“确认更新”。第一期不提供更新全部。

**本地变更：** 新安装/成功更新后记录用于比对的文件摘要基线（不含秘密内容），模型展示字段单独管理。若检测到非该字段的本地修改，阻止更新并提示自行保存/处理后重试，不自动覆盖。旧实例无可靠基线时显示“无法判断本地改动，更新可能覆盖技能文件”，必须明确勾选确认该影响；不声称已备份。此确认仅用于具体未知状态，不给所有操作加通用安全勾选。

**提交与执行：** planId 含 expectedRevision 与单技能身份。提交后重检修订、信任、目标和写入门闩；复用现有针对单个 skill 的 CLI 参数，不改成仓库整包更新。远程在检查后可变化，界面写“更新至执行时源站可用内容”，不承诺精确固定预览版本。

**设置保留：** 更新前保存该实例 `disableModelInvocation`，更新后用现有最小 frontmatter 修改函数恢复这一值；恢复失败是 needs-review，不静默成功。不能恢复整个旧 SKILL.md 覆盖新技能正文。

**核验：** 重读实例、锁信息、来源与实际版本，再尝试比较当前源。本地文件验证失败不能成功。文件更新成功但源站复查失败可为 succeeded，同时 `updateState=unchecked/error`，提示“文件已更新，最新状态未确认”；不能直接写成 up-to-date。返回实际版本与预览不同要明确展示。

**验收：**
- F13-A：一个仓库有多个技能，更新 A 不改变 B；项目/global 实例不串写。
- F13-B：更新前隐藏，更新后仍隐藏；只恢复该字段，不覆盖新正文。
- F13-C：可靠基线检测到本地编辑时阻止；基线未知未确认时不可提交。
- F13-D：CLI 成功后源比较失败，不显示“已是最新”；本地核验失败进入待确认。

## F14 操作记录与故障恢复

**范围：** 最小持久化安装/更新操作账本，放在服务端解析的 Agent 状态目录下；不搭建通用队列/调度平台。记录 operationId、幂等摘要、捕获上下文、阶段、时间、结果引用和脱敏错误；不记录凭据或完整技能内容。

**恢复：** 浏览器仅保存 operationId 与视图入口，重新打开后 GET 查询。服务器重启发现非终态记录，先标 needs-review；不能凭进程不在就自动重放。读目标/锁信息可帮助核验，但不足以确认时保留未知，显示路径和后续动作。

**重复键：** 相同键相同请求返回原操作；相同键不同计划返回 409。并发处理使用可跨实际服务进程的文件锁/已有共享锁机制，不能只用组件变量或单进程 Map 假装全局互斥。锁丢失/陈旧恢复要核验持有者，不能仅超时后开始第二个写任务。

**错误处理：** 解析 HTTP 状态和 Content-Type；现有 Basic Auth 401 可能是文本，应显示重新认证入口，不尝试强制 JSON 造成二次错误。403 权限/信任、409 stale/busy、429 限流、502/504 上游失败分别提供相关动作。显示请求/操作编号，日志清理绝对路径中无关用户信息、凭据及控制字符。

**验收：**
- F14-A：安装中断网，恢复后查询原操作；写请求没有自动重试。
- F14-B：服务重启保留待确认记录，绝不自动再次执行 CLI。
- F14-C：两个窗口不同 key 同时写入，仅一项启动；另一个收到 busy。
- F14-D：401 text/plain、403 JSON、非 JSON 502 都有可读错误而非页面崩溃。

## F15 无项目与未信任项目

**无项目：** 发现、远程详情、全局清单和全局安装可用；项目选项明确不可用。服务端全局只读加载不得用任意临时 cwd 意外加载项目资源，应使用 SDK 支持的禁用项目资源选项或经验证的等价全局读取策略。

**未信任项目：** 显示“该项目的资源尚未加载”；全局管理仍可用。不能枚举未授权/未信任的项目文件正文，不把不可读取项目推断为“项目未安装”。项目操作需要既有信任流程完成后重新读取和预检。

**信任变化：** 每次提交重新校验；预检后撤销信任返回 403，不依赖前端禁用。全局操作仍验证其自身路径授权。

**验收：**
- F15-A：无 cwd 可浏览和安装全局；项目安装无法提交。
- F15-B：未信任项目仍能查看全局列表，项目安装状态标未知/未加载。
- F15-C：计划建立后撤销项目信任，执行被拒绝且没有写文件。

## F16 响应式、键盘与可访问性

**布局：** 宽屏卡片 3 列，中屏 2 列，窄屏 1 列；阈值优先复用项目响应式断点并以最小卡片宽度约束。已安装桌面为列表、手机为堆叠行。安装桌面侧面板、手机全屏子视图。所有主动作在窄屏仍可达。

**键盘：** tablist/tabpanel 正确语义；方向键换标签，Enter/Space 激活动作；弹层 focus trap、Esc 关闭视图、关闭后回到触发点。关闭运行态面板不会取消任务，先显示说明，不伪装“取消安装”。

**读屏：** 每行开关 accessible name 含技能名和位置；结果数/阶段为 polite live region；错误关联字段；状态不用颜色单独表达。焦点可见；触摸目标建议至少 44 CSS px，复用组件控制尺寸。尊重 prefers-reduced-motion，加载反馈不依赖闪烁。

**验收：**
- F16-A：仅键盘完成搜索→详情→确认安装→查看已安装；焦点不中断/丢失。
- F16-B：390 CSS px、200% 文字缩放时路径换行，固定底栏不遮挡内容。
- F16-C：读屏能区分同名不同作用域开关，失败状态可听见。

## F17 缓存、刷新与跨窗口一致性

**缓存键：** 远程原始搜索按 provider+query+limit，分类展示再包含 domainId/categoryId/taxonomyVersion/indexRevision；目录查询按 query+domainId+categoryId+classificationState+taxonomyVersion+indexRevision；详情按 canonicalSkillId+snapshotId；本地按服务端 contextId+inventoryRevision；更新按 installationId+contentRevision+hashAlgorithm+ref。不得跨项目复用本地安装标记。

**刷新：** 安装/更新成功后失效相关 inventory、详情和更新结果；开关只使相应文件 revision/详情/清单失效，不自动制造“内容更新可用”。窗口重新可见时重读本地 revision，已有结果带时间；网络失败允许保留旧可读数据并标注，不用旧状态放行写操作。

**存储与限额：** 缓存 TTL、结果数、预览字节限额、操作轮询间隔、记录保留周期使用统一具名配置；采用既有合理默认值，新增数值需在实现配置中明确来源并测试边界。不缓存凭据到浏览器，不把所有文件正文写入 localStorage。

**验收：**
- F17-A：窗口 A 修改可见性，B 回到前台后刷新；B 的过期 revision 写入仍被服务器拒绝。
- F17-B：离线旧数据仍可阅读，但不能以旧预检直接安装。
- F17-C：更新后详情读取新内容；项目 A 清单不能命中项目 B 缓存。

## F18 兼容、迁移与交付验证

**API：** 保留旧 `/api/skills/*` 的公开请求/响应；新界面使用 `/api/skill-center/*` 聚合合同，底层复用已有服务。旧 route 的校验加强如会改变旧客户端语义，应另行覆盖兼容测试，不能夹带破坏性迁移。

**数据：** 读取已有锁文件、配置路径、手写技能和 frontmatter；不重写整个锁文件以追求新字段。新增实例/操作辅助元数据与 CLI 锁文件分开维护，不能改变 SDK 的资源优先级、默认加载或会话行为。

**界面迁移：** 原技能入口改为打开新中心；旧面板不与新中心同时展示矛盾状态。插件管理仍保持独立，不把插件资源错误计为可直接更新的市场技能。

**验证：** 扩展现有 skill-lock、skill-updates、skill-frontmatter、trust/path 安全测试；增加新合同和端到端主流程。类型检查和 lint 必须运行。遵循仓库 AGENTS：开发期间禁止 next build 污染运行中的 .next；如发布环境需要 build，使用隔离构建目录/既有 CI 流程。

**验收：**
- F18-A：旧 API 代表性调用仍返回兼容结构，既有锁文件与手写技能无需迁移即可显示。
- F18-B：新旧入口不会引起重复加载或重复写操作；原插件管理行为不变。
- F18-C：针对源码修改实际运行的检查记录入发布说明；未运行项目必须显式标注，禁止用设计审阅代替测试。

## F19 五领域总览与导航

**入口与结构：** 发现首页按配置固定显示计算机 computing、金融 finance、哲学 philosophy、心理学 psychology、玄学 metaphysics 五个领域，顺序不可由远程结果变化。总览展示名称、领域介绍及已收录数量/未知状态，并提供全部领域的已收录目录搜索；进入领域后提供该领域二级分类与限定范围搜索。外部搜索使用独立明确入口，不混入目录结果。旧前端/代码界面只属于计算机子领域。操作 tabs 仍为发现、已安装、更新。

**配置与空态：** 使用 GET taxonomy；配置读取失败显示重试，不回退写死的计算机首页。无收录领域显示 0 个已收录与空态，配置尚未取得时数量为未知，二者区分。介绍为内容导航，不编写专业建议。

**验收：**
- F19-A：配置有效时五领域按规定顺序显示；总览可直接搜索全部领域目录，进入金融不出现计算机默认类别。
- F19-B：首次打开进入总览；领域返回总览恢复焦点，不能误触发安装或切 scope。
- F19-C：零收录、配置失败、未知数量分别呈现，不以示例技能填充。

## F20 二级分类与跨领域归属

**分类：** 初稿及稳定 category ID 以 API taxonomy 表为准，后续文案可调但 ID 不能静默复用。归属为 canonicalSkillId 到 domain/category 的多对多记录，每条人工维护映射有真实来源、核查证据与时间。category 必须属于所声明 domain；可仅归属领域，未分二级时 categoryId=null。

**身份：** 同技能出现在多个领域仍复用同一 canonicalSkillId/安装身份，卡片标签可多选显示。无证据即待分类，不根据名字或作者臆测，不把未知均归计算机。待分类不是第六个领域，是独立状态筛选。领域改变不改变文件权限、安装位置、信任或模型展示。

**维护：** taxonomy 与 assignments 经严格校验后按版本原子发布；重复 ID、无效父级、悬空映射、缺来源证据拒绝发布，保留上次有效版本并报告诊断。没有有效版本时返回配置错误，不默默启用部分损坏配置。

**验收：**
- F20-A：同技能归属计算机和金融，两处安装标记一致，不能产生重复安装身份。
- F20-B：未知映射显示待分类，全部领域列表仍展示，不能默认计算机。
- F20-C：悬空分类、重复 ID、缺失证据发布失败，既有有效版本不丢失。
- F20-D：领域内无二级的条目在领域全部中可见；切换领域不改变 scope/开关。

## F21 领域目录检索与覆盖

**两条读取链路：** “已收录目录”查询本地版本化索引，支持领域、二级分类与可选关键词；“外部搜索”使用既有 skills.sh/CLI 关键词检索，暂不把 domain/category 发送为上游支持参数。外部结果单独标注来源与本次结果集合；本地映射可在该集合内分类，无映射项仍显示“待分类”，已知非当前领域项可收起但必须有可见数量和查看入口。

**目录规则：** 已收录目录允许空 query；domainId/categoryId 过滤后按 canonicalSkillId 去重；默认配置收录顺序。返回 totalMatched 仅是当前 indexRevision 内匹配数，覆盖为 local-index，marketTotal=null。索引列表 limit 截取必须提供 returnedCount/truncated，不能当全市场总量。分类多对多的领域计数可能相加超过全局去重数，界面解释。

**真实性：** 索引只存真实来源映射，不是复制市场内容的假数据服务。无金融/哲学等数据时显示空目录并允许用户外部搜索，不能因为外部没有分类就禁止发现未知技能。外部结果保留原始来源顺序，各展示分组稳定保持该顺序；分类筛选仅说明对本次集合生效。目录载入失败不同于零收录。

**验收：**
- F21-A：领域空 query 只查询已收录索引，外部空 query 仍不发网络搜索。
- F21-B：结果显示“本地已收录/本次外部结果”，市场总量未知，不称全市场金融技能。
- F21-C：外部结果含未归类项时仍有可见待分类组，可查看详情并安装。
- F21-D：多领域同技能计数按当前集合去重，截取说明与索引版本可核对。

## F22 跨页领域筛选与恢复

**状态：** 保存操作 tab、domainId（null=全部）、categoryId、classificationState、关键词、结果模式、排序和滚动/焦点。详情与安装返回恢复原领域/分类/查询；已提交操作只绑定既有 canonicalSkillId/捕获目标，导航变化不改变写入。

**管理规则：** 已安装与更新默认全部领域；两页共用一份用户明确选择的领域筛选，不自动继承发现页刚浏览的金融范围。不新增“同步筛选”开关：在任一管理页主动选择领域即更新共享管理筛选。始终显示当前筛选及清除入口；检查全部始终检查当前上下文覆盖的全部实例，结果列表才过滤，并显示隐藏于筛选外的结果数量。待分类必须在全部中可见。

**失效：** 切换领域清除不属于新领域的 category；索引版本更新后重验 ID，删除分类清除并告知；项目切换保留有效领域筛选但重算安装状态与检查结果。迟到响应用请求序号和 taxonomy/index/context 校验，不覆盖新视图。

**验收：**
- F22-A：金融分类→详情→安装取消→返回，原 query/分类/滚动恢复；项目作用域不变。
- F22-B：首次打开更新为全部，计算机、金融、待分类均在；检查全部不受当前领域筛选缩窄。
- F22-C：管理页主动选哲学后切更新保持哲学并显示清除入口，发现页导航不会默改此筛选。
- F22-D：分类删除或领域切换不会残留非法 category；旧响应不能覆盖新分类结果。
