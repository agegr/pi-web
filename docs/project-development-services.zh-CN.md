# 项目开发服务

Pi Web 可以管理项目 `Procfile.dev` 中列出的本地开发进程。请把文件放在项目根目录。例如，Node 项目定义了 `dev` 和 `worker:dev` 两个 package script 时，可以这样写：

```procfile
web: npm run dev
worker: npm run worker:dev
```

每个非空行的格式是 `名称: 命令`。名称用于在 Pi Web 中标识服务；命令会从项目目录运行。空行和以 `#` 开头的整行注释会被忽略。每个服务都要使用不同的名称。

侧边栏中的项目按钮可以启动所有已配置的服务；服务运行时再次点击则会停止它们。悬停或打开服务菜单可查看各服务状态并单独控制。点击服务名称会在右侧面板打开实时日志。关闭面板不会停止进程；可通过面板中的 Stop 按钮或项目按钮停止服务。

读取 `Procfile.dev` 只会发现服务，不会执行命令。只有从侧边栏或服务面板明确启动后，Pi Web 才会运行相应命令。命令通过当前平台的 shell 执行，请只运行信任的命令。
