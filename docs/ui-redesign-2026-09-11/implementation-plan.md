# Clear Horizon 实施计划

设计前置已完成：20 张独立图片，已选第三版，详见 comparison.md。用户授权保留全部功能并重组布局与入口。本计划在完成设计图后编写，按以下顺序执行。

## 验收标准

- 20 个对应状态均能在现有应用访问；功能入口、真实数据、错误和禁用逻辑保留。
- 白/冰灰表面、深蓝正文、钴蓝重点统一；桌面顶栏容纳项目与 worktree，侧栏专注会话和文件。
- 1280×720 桌面、390×844 手机无页面级横向溢出；源码自身允许横向滚动。保留深色/系统主题。
- 空会话、空配置、无项目状态有准确说明；不增加假会话、假模型、假版本、假快捷键或不可用操作。
- 类型检查、lint、相关测试通过；浏览器验证主要切换和配置入口。缺凭据的联网模型/安装/流式场景仅做代码保持检查，不宣称运行验收。

## 步骤与覆盖

1. **共享视觉变量与设置（02–04、14–17）**：在 globals.css 设置主题令牌；调整 settings.css 和 SettingsUi/各 Config 的既有类，扩大字号和控件。手机空资源列表紧凑呈现。检查一般设置切换、供应商选择、技能搜索/插件来源输入和空安装禁用。
2. **工作台与上下文导航（01、05–09、20）**：复用 SessionSidebar 中唯一项目/worktree 状态，将桌面选择器呈现在顶栏；保留手机侧栏和其所有能力。增加清晰的首次进入/项目空会话说明，分组现有顶部操作，调整目录弹窗。检查项目切换、选择器关闭、创建分支输入禁用及手机菜单。
3. **聊天与文件（07、10–13、18–19）**：更新输入容器、工具栏、推理/工具预设菜单；保留发送/停止、附件、队列、压缩、声音、模型和命令逻辑。优化文件标题与 Source/Preview/Diff 工具栏和移动端。检查菜单枚举、只读预览/源码、引用与换行。
4. **整体验证与记录**：执行 typecheck、lint、已有相关测试；同尺寸实际截图与设计放在一起比较，修复遮挡、溢出、对比度和入口回归；保存 design-qa.md、实装截图与结果。

## 实施取舍

- 图片中有生成误差：Ctrl K 新建提示、伪版本号、空会话选择行、重复模型入口及 README 文案不作为实现规格。
- 使用既有组件、图标和系统字体，不新增 UI 框架、不升级依赖、不更改 API。不挂载当前未使用的 AgentsConfig。
- 调整现有语义 token，新增尺寸/阴影 token 集中维护；保留主题适配和减少动画偏好。
- 不覆盖任务开始时已有未提交修改，不提交或推送代码。复用健康的 30141 开发服务；按项目说明不运行 next build。
