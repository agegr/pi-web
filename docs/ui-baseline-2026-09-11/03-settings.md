## SET-00 设置容器及公共交互

### 当前实现

- 通用和模型无项目也可打开；技能、插件要求存在 `cwd`，否则禁用并显示需要项目的提示。
- 关闭按钮、遮罩点击和 Escape 均可关闭设置。
- 页签首次访问时挂载，之后隐藏而不卸载，保留内部状态。
- 记忆最近设置页，以及模型等详情选中项。
- 桌面为顶部横向页签；640 px 及以下切为下拉选择。共享分栏也有移动适配。
- `ConfigPanelShell` 支持独立弹窗和嵌入模式；实际设置内使用嵌入模式，不重复显示标题与关闭按钮。
- 公共组件覆盖分栏、分组列表、详情头部、字段、空状态、底部状态栏、主/次/危险/ghost 按钮、开关和状态点。
- 开关提供 `role="switch"`、`aria-checked` 和 label，加载期间禁用。

源码：[SettingsPanel.tsx](../../components/SettingsPanel.tsx)，192、209、222、235、256 行；[SettingsUi.tsx](../../components/SettingsUi.tsx)，19、76、234 行；[settings.css](../../app/settings.css)，1055 行。

### 对比与建议

| 当前基线 | 建议优化 | 对比验收 |
| --- | --- | --- |
| 即时生效和手动保存共存 | 每页明确保存方式及作用范围 | 用户能区分已应用、未保存、保存中 |
| 切页保留挂载状态 | 保留此行为，补充未保存反馈 | 切页后草稿不意外丢失 |
| 桌面页签、移动下拉 | 统一选中状态和页面标题 | 两种尺寸均能辨认当前位置 |
| 详情有时依赖左栏识别对象 | 增加清楚的详情标题和次要元信息 | 不看左栏也能辨认编辑对象 |

## SET-01 通用设置

### 字段、操作与状态

- 外观：浅色、深色、跟随系统；图标加文字，单选语义，立即应用。
- Windows 条件显示 Shell 工具：PowerShell 开关；写入设置后，有当前会话则触发 reload。
- 语言：来自 `supportedLocales`，显示语言名称和 locale code，立即应用。
- PowerShell 保存中禁用，保存错误以 `role="alert"` 呈现。

源码确认的可见性问题：首次加载 Shell 设置失败会记录错误，但错误元素位于 `shellSettings?.isWindows` 条件中，尚未取得设置时错误不可见。这里只确认渲染条件，未在浏览器触发网络失败。

源码：[SettingsPanel.tsx](../../components/SettingsPanel.tsx)，69 行请求、83 行修改、115 行主题、141 行 Shell 条件、159 行错误、165 行语言。

建议：主题增加简洁预览；统一语言与主题选择控件；加载错误放在条件分区外并提供重试。对比应覆盖浅/深/系统、不同语言、Windows Shell 开关及失败态。
