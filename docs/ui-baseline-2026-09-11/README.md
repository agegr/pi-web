# Pi Web 前端功能页面基准与优化对比

记录日期：2026-09-11。版本：Pi Web 0.8.11 / Pi 0.84.3；pi-web HEAD：`28bab3c`，包含本机已有未提交修改，因此这是一份当前工作区基准，不是上游发布版本截图。

本资料按用户真正看得到的工作台、面板、弹窗、菜单和动态状态盘点。Pi Web 使用单页工作台，不能把一个 API 或一个组件文件直接当成独立产品页面。当前共整理 **77 个可达功能界面/状态分组**：工作台 W01–W16、文件 F01–F14、聊天 C01–C31、设置 16 项；另列 1 个无入口保留组件 AGT-X。一个分组可能含多个状态，不代表 77 个 URL，也不表示全部状态都已运行截图。

## 阅读入口

- [完整图文画册与对比文档（HTML）](index.html)：将下面所有文档和 20 张截图合并，适合浏览器阅读和打印。
- [工作台、会话管理与文件界面](01-workspace-files.md)：30 个功能分组，包含项目、worktree、会话管理、文件类型与手机布局。
- [聊天界面清单](02-chat.md)：31 个功能分组，包含输入、运行、消息、分支、Agent、扩展交互。
- [设置界面清单](03-settings.md)：常规、模型、技能、插件的全部字段/子状态，以及未接入的 Agent 配置说明。
- [优化对照与验收表](04-comparison.md)：现状对比建议、优先级、后续前后对照模板和缺失截图清单。

## 证据与限制

1. **源码确认**：检查了页面入口、AppShell 的挂载路径、功能组件和相关样式/测试。每组功能附实现位置。行号为本次调查位置，后续代码变动可能使行号漂移。
2. **浏览器观察**：本机 `http://127.0.0.1:30141`，简体中文，系统主题在截图中呈浅色；桌面 1280×720，移动模拟 390×844。原始截图未经重绘。
3. **实际环境**：没有历史会话、已配置模型、已安装技能和插件。因此动态聊天、认证成功、资源详情等只给源码说明，没有伪造图片或宣称测试通过。
4. **已有本地修改**：开始前已有 AGENTS.md、next.config.ts、package.json、package-lock.json、lib/next-config.test.mjs 修改，以及 .npmrc、lib/local-pi/、lib/local-pi.test.mjs 未跟踪内容。本次仅新增本目录文档/图片。开发服务器可能维护 AGENTS.md 的 Next.js 生成块，该文件不纳入本次文档交付。
5. **对比含义**：目前没有新的设计稿；“优化后”是建议方向和待填写位置，不是已完成改版。原图用于下一轮同条件比较。
6. 截图内的更新提醒、Git 变更数量等是抓取时状态；变更数量也可能包含本次新文档，不可当作产品固定数据。开发模式角落的 Next.js 图标不是产品功能。
