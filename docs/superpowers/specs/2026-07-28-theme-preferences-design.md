# 主题偏好与通用设置样式设计

## 背景

设置中心已将主题、语言和安全设置集中到通用与安全页面，但通用页的选项卡片比模型配置页的条目更宽松，语言选择也不能自然适应后续注册的语言包。主题目前只有浅色和深色两种显式状态，不能持续跟随系统外观变化。

本次改造以模型配置页为视觉基准，仅调整通用和安全页面，并将主题偏好扩展为跟随系统、浅色、深色三态。

## 目标

- 主题偏好支持跟随系统、浅色、深色，并在跟随系统状态下实时响应操作系统外观变化。
- 语言选择改为单个下拉框，选项来自当前注册的所有语言包。
- 通用和安全页面的可见控件密度、圆角、字号、边框、交互状态与模型配置页保持一致。
- 保留既有主题动画、本地持久化、语言持久化、密码校验与改密成功后的注销流程。

## 非目标

- 不调整模型、技能或插件页面的样式与布局。
- 不重写主题、语言或密码相关的服务端 API。
- 不新增其他外观偏好或语言包。
- 不强行让密码输入、保存按钮等不同语义的控件使用模型列表条目的尺寸。

## 已确认行为

### 主题偏好

- `pi-theme` 保存三种偏好值：`system`、`light`、`dark`。
- 选择 `system` 时，当前有效主题取自 `prefers-color-scheme: dark`。
- 操作系统主题在页面打开期间变化时，应用立即同步更新有效主题。
- 选择 `light` 或 `dark` 时，不再响应系统外观变化。
- 既有保存的 `light` 与 `dark` 值继续有效；缺失或无效值按 `system` 处理。
- 初始 HTML 内联脚本按同一规则设置 `html.dark`，避免首屏主题闪烁。
- 保留现有 View Transition 动画；系统变化和不支持动画的环境直接更新 DOM 状态。

### 通用页面

- 主题使用紧凑三段按钮，顺序固定为跟随系统、浅色、深色。
- 三段按钮的行高、字号、圆角、横向内边距、hover、选中与键盘焦点规则对齐模型配置页左侧条目。
- 语言使用一个原生 `<select>`，当前值绑定 i18n locale。
- `<select>` 的 options 直接映射 `supportedLocales`，因此语言包注册数量变化时自动反映在 UI 中。
- 主题和语言更改立即生效，不提供保存按钮。

### 安全页面

- 安全页保留当前密码、新密码、确认新密码、错误提示和提交行为。
- 标签、输入框、错误提示、操作按钮和垂直间距改为与模型详情表单相同的紧凑视觉语言。
- 密码不一致校验、`POST /api/auth/password`、稳定错误码翻译、网络错误处理，以及成功后注销均不改变。

## 架构

### `hooks/useTheme.ts`

主题 hook 负责偏好与有效主题的转换，公开当前偏好、当前有效主题和一个显式设置偏好的方法。它维护一个共享的 `matchMedia` 订阅，仅在偏好为 `system` 时响应系统事件，并在订阅清理后不再更新应用状态。

现有仅能翻转浅深色的调用方改为选择明确偏好。主题变更的 DOM class 与 localStorage 写入仍在 hook 内集中处理，避免设置页面和首屏逻辑产生状态分叉。

### `app/layout.tsx`

首屏脚本读取 `pi-theme`。`dark` 直接添加 `html.dark`；`light` 直接保持浅色；`system`、缺失或无效值读取 `prefers-color-scheme` 后决定是否添加 class。此脚本与 hook 使用相同的兼容规则。

### `components/SettingsModal.tsx`

`GeneralSettings` 使用主题 hook 渲染三段按钮，使用 i18n hook 渲染一个语言 `<select>`。通用和安全内容使用共享 class，不保留当前较大的独立选择卡片网格。

`ModelsConfig` 是视觉基准，不在本次范围内修改。技能和插件同样不改动。

### `app/globals.css`

新增或调整仅供通用和安全页面使用的共享设置 class。它们采用模型页的紧凑条目尺度和现有 CSS 变量，不新增颜色、字体或新的全局设计语言。

## 无障碍与错误处理

- 主题分段按钮继续使用原生 button 与 `aria-pressed` 表示选中状态。
- 语言下拉框具有对应的可见 label。
- 主题、语言和密码控件均保留可见键盘 focus 样式。
- `matchMedia` 不存在时，`system` 安全降级为浅色，且不抛出运行时错误。
- 主题监听在切换为显式偏好或组件卸载后清理，避免重复监听与陈旧更新。
