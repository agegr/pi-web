# pi-web 🚀

**pi-web** 是专为 Pi 智能体（Agent）对话、工作区会话管理、文件预览以及本地 Git 协同而精心二次重构的专属、高体验、极轻量网页后台及桌面壳体。

它不仅可以作为独立的网页服务运行，还支持通过 Tauri 深度打包为在 Windows、macOS 上免安装 Node 环境、轻盈小巧的桌面客户端应用。

---

## ✨ 核心亮点与高体验重构

在本次深度维护与体验打磨中，我们基于原生设计，针对开发人员的高频场景进行了重构和升级：

### 1. 📁 智能项目级工作区管理
* **项目隐私保护**：彻底废除了凌乱、容易在面包屑和列表中截断的绝对路径修剪算法。顶部 header 与工作目录列表均完美显示**真实的末级项目文件夹名**，并在括号中备注全路径。
* **无损历史清理（Forget/Hide Folder）**：在侧边栏的项目悬浮菜单中增加 **一键 `X` 隐藏** 按钮。在主界面上暂不关心的历史历史工作目录可以无损隐藏，隐秘掉老旧项目；再次导入时，对应工作区与其会话树（包括历史分叉）将立刻完整无损复原。
* **面包屑秒速级跨目录切换**：工作区 Breadcrumbs 面包屑支持点击上级目录跨级秒跳转，提供一键点击铅笔图标以手写/粘贴绝对路径；下拉列表内置内联模糊搜索，秒级定位子文件夹。

### 2. 🔍 “鱼眼透镜”微缩 Minimap (Fish-eye Navigation & Displaced Tooltip)
* **海量长会话导航**：为了解决超长会话中消息气泡和小圆点紧密堆积、无法选取和精准交互的问题，我们独创引入了**空间变焦鱼眼镜头**微缩总览面板。
* **物理畸变变焦缩放**：当鼠标经过 Minimap 时，悬浮点位及其最近邻临界区（上下 15% 范围）应用二次递减插值。小圆点会平滑摊直、排开，并放大至最高 **1.8x** 比例，建立舒适的点按热区。
* **绝对对齐提示框**：Tooltip 渲染坐标紧密跟随经鱼眼计算变形后的圆点视觉坐标，彻底解决了堆叠、遮挡的积弊。点击即可向主视口发送 smooth-scroll 指令精确居中历史卡片。

### 3. @ 智能文件联想注入
* **全光标感知检索**：在输入框任意位置键入 `@` 字符，即刻召唤高精细度本地文件检索面板。
* **极速过滤与 Tab 补全**：继承键盘 `Tab` 与 `Enter` 快捷键，极速选中并补全。文件带有与特定系统语言相呼应的扁平化文件类型图标。

### 4. 💻 光标感知与中途斜杠 Skill 唤醒 (Caret-Aware Slash Trigger)
* **打破首字符局限**：无需再保证斜杠 `/` 必须处在输入框行首。即使在输入了多行内容、文字中段、或换行后，仅需键入 ` /` 即可触发 Skill 选择菜单。
* **非破坏性文本重构**：选定预设高级智能体技能（如 `/skill:tdd` 等）后，系统会精准替换斜杠对应的输入片段，完美保护并保留该片段前后的历史文本输入。

### 5. Code 缓冲与流式安全呼吸滚动
* **避免首部溢出遮挡**：修复了在智能体输出超大代码块或长文本时，流式强拉滚动条把代码块头部顶出视口、迫使用户每次都要手动往回滚的历史缺陷。
* **呼吸安全底座**：在底部特设一个弹性空腔，配合增量平滑滚动算法，保证所有的文本行、连绵生成的代码逻辑卡片都能平滑、优雅地居中动态呈现在视口中。

### 6. 💻 宿主原生终端一键唤醒
* 在主界面顶栏可以一键快速唤醒宿主原生的高级命令行终端（Windows 优先唤醒 Windows Terminal 并按需平滑降级到 PowerShell；macOS 一键拉起系统 Terminal），完美继承用户当前的本级开发工具链（Local-Toolchain）与 Shell 环境，兼具极佳响应度，零内存冗余压力。

## 🚀 快速启动

### 方式 A：免安装，直接运行
如果您的电脑中已装有 Node.js + npm，直接在工作区目录中呼唤：
```bash
npx pi-web
```

### 方式 B：通过全局 CLI 指令
作为开发环境的日常工具，支持全局一键映射：
```bash
# 全局安装项目
npm install -g .

# 启动专线，支持自定义端口
pi-web --port 30141
```
打开浏览器载入 [http://localhost:30141](http://localhost:30141) 即可开始。

### 方式 C：离线团队分发
对于网络受限的封闭开发系统，提供快速单文件部署机制：
```bash
# 打包生成发布压缩包 pi-web-1.0.0.tgz
npm pack

# 分配给目标机器后，一键离线强力部署
npm install -g ./pi-web-1.0.0.tgz
```

想进行二次开发、扩展自定卡片 UI 或对接新能力：

# 2. 跑起 Next.js 热更新调试

项目配备了严格的类型编译和规范验证，提交代码前请务必确认通过：

## 📂 项目模块结构树

```
app/
  api/
    sessions/               # 读写底层 .jsonl 会话及分叉依赖
    sessions/[id]/context/  # 支持会话内分支切换的关键多节点树渲染上下文
    agent/                  # 智能体指令收发、流式状态交互
    agent/[id]/events/      # SSE(Server-Sent Events) 单向长连接
    files/                  # 本地文件读取、只读文件沙箱适配
    models/                 # 模型中台路由、热重载配置
    models-config/          # 读写更新本地 ~/.pi/agent/models.json 映射
    git-status/             # 托管 Git 提交、Diff 算法、各分支比对、回滚 hunk
components/
  AppShell.tsx              # 自研面包屑、顶层卡片选项卡控制中枢
  SessionSidebar.tsx        # 极简树级会话管理与下置折叠 EXPLORER 资源树
  ChatWindow.tsx            # 流式消息接收、SSE 处理、防丢居中滚动逻辑控制
  ChatInput.tsx             # Caret斜杠、@联想文件、工具中控面板的高质交互输入
  GitPanel.tsx              # IDEA 级多栏目极度精平 Git 可视化管理器
  FileExplorer.tsx          # 轻量不占位、零 Emoji 本地代码树
  FileViewer.tsx            # 多Tab代码文件与 Git 界面容器
lib/
  session-reader.ts         # 精确读取、合并流式多版本分叉会话格式
  rpc-manager.ts            # 高保活、防冲突、智能锁 concurrency-lock 的会话生命控制
  normalize.ts              # 弥补字段不一致性的 normalization
```

会话存储位置保持一致：`~/.pi/agent/sessions/<编码后的工作目录>/<时间戳>_<uuid>.jsonl`。

## ⚠️ 避坑与注意事项

1. **缓存排他锁**：一个工作区项目同时只能存在一个运行态的 Session 会话底层实例。系统通过 `rpc-manager` 对同秒发出的多次请求进行了锁屏串行化避让阻尼（Concurrency Lock），不要在后台手动多实例绕过。
2. **数据目录变迁**：会话本地物理层日志完全依赖于 Pi 智能体标准目录。你可以通过设定操作系统环境变量 `PI_CODING_AGENT_DIR` 强行覆盖当前的日志目标路径。
3. **模型变动实时重载**：侧栏中的 Models 按钮可调出配置面板，所有对 `models.json` 的修改都可以热生效，无需重启命令行宿主进程。
